# portfolio

A clean, futuristic personal portfolio site. Plain HTML/CSS/JS with no build step.

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

## Customize

- **Content**: edit `index.html` (name, bio, projects, skills, email, social links).
- **Colors / fonts**: tweak the CSS variables at the top of `styles.css`.
- **Typing words**: change the `data-words` attribute on `.typed` in the hero.

## Deploy

Works as-is on GitHub Pages, Netlify, or Vercel: point it at the repo root.
